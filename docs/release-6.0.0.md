# OnlyKey App 6.0.0

OnlyKey App 6.0 is a complete rewrite of the desktop app. Same key. Same jobs. A much better way to do them.

Coming from 5.6, everything you rely on is still here: setup, slots, keys, backup and restore, preferences, and advanced options, for both OnlyKey and Duo. What changed is the app around them.

### What's new

- **A modern desktop app** for Windows, macOS, and Linux, with a light and dark theme.
- **Stays in the tray.** Close the window and it keeps running. You can start it at login, and launching the app again brings the window back.
- **Password generator** in the slot editor. It writes the password straight into the field and never touches the clipboard.
- **Firmware updates that stay out of the way.** The app can check for a new version, verify the download (SHA-256), and wait for you to load it. The prompt does not cover your PIN, and it works for OnlyKey and Duo.
- **App updates you can trust.** When a new version is published, the app checks it, verifies the installer, and can start the install for you.

Your OnlyKey does not need new firmware just to use this app. Plug in, unlock, and go.
